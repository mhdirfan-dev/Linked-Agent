Agent Brain

The reasoning chain

All 10 steps fire inside a single GROQ API call. The full log is shown to you so the agent's thinking is never a black box.

01
Extract
Technology, achievement, key metric, audience, and pain point from your raw draft.
02
Hook Gen
Two hooks — educational "Here's exactly how I…" and career "I almost quit. Then…" Both fit inside the 210-char cutoff.
03
Format
Max 2 sentences per paragraph, aggressive line breaks. Mobile dwell time increases 40% with whitespace.
04
Hashtags
Picks N tags from a curated high-follower pool. N is dynamically set by your analytics history.
05
Mentions
Scans draft against 19 known LinkedIn page handles. Tagged entities expand reach 3–5× organically.
06
CTA
Appends a direct question. Comments signal "meaningful conversation" to the feed algorithm.
07
Comment
Writes the first comment (50–80 words) with 2–3 bonus hashtags not used in the main post.
08
Checklist
7-rule pass/warn/fail evaluation. Hook, structure, hashtags, mention, CTA, word count.
09
Carousel
Detects tables and lists ≥4 items. Extracts them for the PDF carousel export.
10
Score
0–100 weighted: Hook 30 · Structure 20 · Hashtags 15 · CTA 15 · Mention 10 · Length 10.
Microsoft Foundry IQ

The agent doesn't guess. It retrieves rules, cites them, and adjusts them based on what actually worked.

Foundry IQ is the knowledge retrieval layer that prevents hallucinated advice. The agent's system prompt is built entirely from structured rules sourced from LinkedIn algorithm research — with an explicit citation in every response. The knowledge base is not static: it re-calibrates itself based on your real post performance history.

01
Knowledge Base
rules.js — structured LinkedIn algorithm rulebook covering hooks, structure, hashtags, mentions, and CTAs.
02
Grounded Retrieval
buildFoundryIQPrompt() constructs the system prompt from retrieved rules — reducing hallucination, keeping output verifiable.
03
Dynamic Updating
updateRulesFromAnalytics() re-calibrates the hashtag rule based on your post performance. The knowledge base learns.
04
Cited Response
Every agent response includes iq_citation — a sourced reference to the rule version used. No untraceable output.

Security

How it stays safe

🔒
API key never in source code
config.js is gitignored. On Vercel, the key lives in environment variables and is injected by a serverless function — not visible in any committed file or browser network tab that shows source.
🛡️
XSS protection on all user content
Every piece of user input rendered to the DOM passes through escHtml(). Malicious draft content cannot inject scripts.
🔐
No data leaves your browser except the GROQ call
No backend, no database, no analytics service. The only outbound request is the GROQ API call. Everything else — analytics, images, history — stays in localStorage on your device.
🧹
JSON sanitizer prevents crashes
sanitizeJsonString() repairs malformed JSON from the LLM before parsing — handling unescaped control characters and bad newlines that would crash a naive JSON.parse.
